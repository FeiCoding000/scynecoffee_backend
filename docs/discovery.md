# Discovery

## Purpose

The purpose of the discovery phase is to understand the current ScyneCoffee system, identify business and technical challenges, and define opportunities for improvement.

---

## Stakeholders

The system involves:

- Coffee system users
- Baristas
- System administrators
- Developer

---

## Discovery Activities

The following activities were performed:

### System Review

Reviewed:

- Existing frontend application
- Firebase integration
- Current data structure
- Existing user workflow


### Technical Assessment

Reviewed:

- Authentication approach
- Data access pattern
- Frontend-service coupling
- Data model design


### Business Process Review

Analysed:

- User onboarding
- Coffee ordering workflow
- Order status management
